17/// @brief A compile-time sequence of types.
18///
19/// `TypeSeq` is used to represent an ordered collection of types at compile time.
20/// It is primarily intended for manipulating lists of tags or types in generic
21/// programming code.
22///
23/// The order of the types is significant for operations such as
24/// @ref type_seq_rank_v, @ref type_seq_element_t, and the sequence manipulation
25/// utilities.
26///
27/// @tparam Tags The types contained in the sequence.

29struct TypeSeq
30{
31};
